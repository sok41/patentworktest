# market-research（市場調査スキル）

## 入力

- 案件フォルダ内 `00_overview.md` の「市場調査観点」セクション
  （対象市場・製品領域／知りたいこと（市場規模／プレイヤー／トレンド等）／その他の指定条件）

## 調査範囲

- 特に指定がない限り、調査対象地域は**ワールドワイド（グローバル）**とする。日本国内に限定しない。
- `00_overview.md` の「その他の指定条件」等で対象地域が明示されている場合はそれに従う。

## 処理手順

1. `00_overview.md` の市場調査観点を読み取る。記入が不十分な場合はユーザーに確認する。
2. Web検索等により、市場規模・主要プレイヤー・トレンドをワールドワイドで調査する。
3. 出典（参考URL）を必ず記録する。
4. ユーザーから主要プレイヤーについて**追加の詳細調査**を求められた場合（「主要プレイヤーを詳しく調べて」「企業プロフィールも作って」等）は、下記「主要プレイヤー詳細調査フォーマット」に従って対象企業ごとにまとめる。指定がなければ通常の主要プレイヤー概要（社名・概況程度）のままでよい。

## 主要プレイヤー詳細調査フォーマット

`market_research_output.md` の「主要プレイヤー」セクション配下に、対象企業ごとの小見出し（`### <企業名>`）を作り、以下の項目を簡潔にまとめる。情報が見つからない項目は「不明」と明記し、憶測で埋めない。

```
### <企業名>

- 正式名称
  - 英語表記:
  - 現地語表記:
- 会社規模
  - 設立年:
  - 資本金:
  - 従業員数:
  - 直近の売上高:
- 主力事業:
- 企業Webページ:
- 主要技術:
- 子会社を含む関連会社情報:
- 強み・弱み（SWOT分析のような視点）
  - 強み:
  - 弱み:
- 主要な取引先・競合企業
  - 日本企業:
  - 日本企業以外:
- その他、関心を持たれそうな関連情報:
```

## 出力

- `01_research/market/market_research_output.md`
  - 市場規模
  - 主要プレイヤー（詳細調査を求められた場合は企業ごとのプロフィールを含む）
  - トレンド
  - 出典・参考URL

出力時は `projects/_template/01_research/market/market_research_output.md` の見出し構成（トップレベルの4見出し）を維持すること（`post_tool_use_validate.sh` が必須見出しの有無をチェックする）。企業ごとの小見出しはその配下に自由に追加してよい。

## 完了時の処理

1. `status.yaml` の `phase.market_research` を `done` に更新する。
2. `projects/_index.md` の当該案件行を更新する。
3. `status.yaml` を確認し、`phase.patent_research` も `done` であれば `patent-analysis` スキルへの着手をユーザーに提案する。まだ `done` でなければ、特許調査の完了を待つ旨を伝えて待機する。
