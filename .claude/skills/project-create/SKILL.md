# project-create（案件フォルダの新規作成）

## トリガー

「〇〇に関するプロジェクトを作成して」「〇〇の案件を新規で立てて」など、**調査観点の具体的な中身（00_overview.mdに書く内容）を伴わずに**、案件フォルダの作成だけを求められた場合に使う。

すでに調査観点の具体的な内容（対象技術分野・対象市場など）と共に依頼された場合は、このスキルではなく CLAUDE.md 1章の「調査概要を投げることでプロジェクトが開始する」ルールに従い、`00_overview.md` への記入まで一括で行ってよい（`project-create` → 内容記入 の2段階を省略できる）。

## 処理手順

1. 案件名から案件IDを組み立てる: `YYYY-MM-DD_案件名スラッグ`（`YYYY-MM-DD`は本日日付、スラッグはユーザーが指定した案件名。日本語のままで構わないが、ファイル名として問題のある文字は避ける）。
2. `projects/` 配下に同名の案件ID（進行中・アーカイブ問わず）が既に存在しないか確認する。存在する場合はユーザーに伝え、別名にするか既存案件を使うか確認する。
3. `projects/_template/` を `projects/<案件ID>/` にそのままコピーする。
4. `status.yaml` の `project_id` と `created_at` のみ記入する（`phase` は全て `not_started` のまま、`archived: false` のまま）。
5. `00_overview.md` の「案件名」「開始日」欄のみ記入し、「特許調査観点」「市場調査観点」セクションは空欄のまま残す（ユーザーが後で記入するため）。
6. `projects/_index.md` に該当案件の行を追記する（現フェーズ: `not_started`、ステータス: `not_started`、更新日: 本日）。
7. ユーザーに「案件フォルダ `projects/<案件ID>/` を作成しました。`00_overview.md` に調査観点を記入してください」と伝える。

## 完了時

このスキルはフォルダを作るだけで、調査は開始しない。`00_overview.md` の記入後、ユーザーから調査開始の依頼（「〇〇についての調査・分析を開始して」等）があれば `research-kickoff` スキルに進む。
