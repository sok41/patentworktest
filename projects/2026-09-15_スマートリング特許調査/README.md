# 案件テンプレートの使い方

新しい案件を始めるときは、このフォルダをコピーして使います。

## 手順

1. この `_template` フォルダを `projects/` の下にコピーする
2. コピーしたフォルダ名を `YYYY-MM-DD_案件名スラッグ`（例: `2026-09-14_ドローン特許調査`）に変更する
3. `00_overview.md` を開き、案件名・特許調査観点・市場調査観点を記入する
4. `status.yaml` の `project_id` と `created_at` を記入する
5. Claude Codeに「新しい案件として〇〇を始めたいです」と伝えて開始する

※ Claude Codeに「新しい案件を始めたい」と伝えるだけで、1〜4の作成・コピー・記入まで自動化することも可能です。運用しながら、手動でやりたい範囲と自動化する範囲を調整してください。

## このフォルダに含まれるもの

| ファイル / フォルダ | 役割 |
|---|---|
| `status.yaml` | 案件の進捗管理（各フェーズの状態） |
| `00_overview.md` | 調査概要（特許観点・市場観点を記入） |
| `01_research/patent/research_output.md` | 特許調査スキルの出力先（テンプレート済み） |
| `01_research/market/market_research_output.md` | 市場調査スキルの出力先（テンプレート済み） |
| `02_analysis/analysis_output.md` | 分析スキルの出力先（テンプレート済み） |
| `03_report/` | レポート作成スキルが `final_report.docx` を生成する場所（空でOK） |

このREADME.mdは案件フォルダ内に残しておいても、コピー後に削除しても構いません。
